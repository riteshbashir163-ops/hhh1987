# S姐结构手册（标题｜开篇｜正文图文｜结尾）

## 一、交付骨架（只交四件，固定栏目件一律不写）

```
① 爆款标题 1 个（markdown格式，行首加 # ）
② 开篇：纯文字无图，立意铺垫，零搭配细节
③ 分组正文：2~4个小标题（markdown格式，行首加 ## ），组内"文字段→【图X】"交替
④ 结尾：1~3句收束，从"衣"落回"人/心/生活"
```

## 二、标题公式（每篇现做，不能偷懒）

**公式**：「"核心单品/组合"」＋「流行程度词」＋「效果情绪词」＋「！」
流行程度词：今年X天火出圈了 / 最火 / 突然火了 / 太火了 / 又火了 / 才是X天的"顶流" / 最流行
效果情绪词：怎么搭都时髦好看 / 又飒又美好看绝了 / 减龄好看 / 清爽随性又百搭 / 时髦高级炸了 / 优雅气质全靠它

要求：15~25字；含单品名（可加引号）；季节准确；情绪强。

合格参照：
- "卡其裙"今年春天火出圈了，怎么搭都时髦好看！
- "马蹄鞋"今年秋天突然火了，怎么搭都减龄好看！
- 这件衣服才是早秋的"顶流"，优雅气质全靠它！
- 初秋最火的"牛仔阔腿裤"，搭配这三件上衣好看绝了！
- "小棕鞋"今年又火了，不管搭配裤子，还是裙子都很时髦高级！

## 三、开篇八式（选最贴主题气质的一种，别篇篇同款）

1. **观念/文化切入**（意境流主打）："为什么喜欢混搭？无非是喜欢换一种花样去生活工作的感觉……"
2. **季节/天气切入**："立秋之后，裤装就成了日常利用率最高的单品。"
3. **困扰/痛点切入**："穿衣服具有局限性，是很多小个子女生的困扰……"
4. **电影/人物切入**："《蒂凡尼的早餐》里赫本一身经典到永恒的小黑裙装扮再次惊艳了我。"
5. **宣言直给**："是的，就是粉色。"
6. **互动提问**："这个火辣辣的夏天，你们都喜欢怎么穿呢？"
7. **自我故事**："最近吃的有点HIGH，腿上的肉肉已经迫不及待地想要撑破裤子溢出来……"
8. **引言起兴**："'女为悦己者容，悦己者，方能悦人'。"

**开篇五铁律**：
- 只立意不给答案：零搭配细节，最多点出主角单品；
- 由虚入实的固定坡道：情绪/现象→（原因）→单品登场，靠"而/所以/这时候/那么接下来"过渡；
- 篇幅两档：意境流5~10段200~400字；种草流2~5段100~200字；
- 常带一次设问，替读者把问题问出来；
- 纯文字，不插【图X】；
- 禁论说文腔：不下判断讲道理（"流行从来都是轮流坐庄"式论证），
  用絮语起手（"不知道从什么时候开始""与其说是…不如说是…"），详见 yufeng.md 第五节。

## 四、正文：分组与图文关系

**六种组织法（按图片变量选其一）**：
| 组织法 | 逻辑 |
|---|---|
| 公式分组 | 核心单品＋变量：「风衣+卫衣 / 风衣+裙子」 |
| 品类分组 | 同主题按单品切：「条纹衬衫 / 条纹裙 / 条纹裤」 |
| 色系分组 | 「粉+黑白 / 粉+驼 / 粉+蓝」 |
| 人物案例 | 按博主穿搭规律切章节 |
| 人群分组 | 按肤色/身材/个子给方案 |
| 方法论分组 | 「怎么选 / 怎么搭」两段式 |

**小标题**：格式固定为 `## 单品名/组合名`（如 `## 灯笼裤`、`## 衬衫+高腰裤装`）。
不加序号、不加引号、**不加描述性副标题行**（禁止"灯笼裤／自由自在的松弛风"这种两行式）。

**图文五铁律（本文体的命门）**：
1. **文先图后**：先写文字段（1~3句一段），段末换行独立写`【图X】`；一个论点段配1~3张图；
2. 文字只写穿法、效果、适配人群，**绝不描述图中人物动作、手持道具、背景场景**；
3. 不编造图中没有的单品；
4. 意境流全文不指图（不说"左图/上图"）；仅教学对比时才允许指认方位并用×/√；
5. 多人物图片只选一套最符合主题的写，另一套至多半句带过，禁止"左边右边"逐套拆解。

**段落律动**：一段1~3句、一句一意；段落长短参差，禁止机械等长；每组结尾可给1句决策建议（肤色/身材/场合）。

**"为什么好看"用看得见的状态说，不用分析词**：
不说"比例优化"，说"腿一下子长了"；不说"材质对比层次"，说"软糯的针织压住了皮衣的硬劲"；
不说"颜色呼应"，说"鞋和内搭顺色，整套和起来"。分析词（搭配逻辑/色彩关系/体量感）禁止直接入文。

## 五、结尾六式（1~3句就停，不总结要点，不说教）

1. **名言升华**（意境流）：引黑塞、泰戈尔式的一句，加半句自己的话收住；
2. **哲理回环**：把单品上升为心性，与开篇立意呼应："想要穿好红色，请给予它一颗足够丰富坦荡的心。"
3. **轻快号召**（种草流）："快一起穿起来吧~""盘它~"
4. **设问互动**："您们夏季最爱的配色是什么呢？"
5. **反问回击**（呼应文中埋的梗）："谁说雨衣不时髦？"
6. **季节祝福**："让我们在这个春天有美好的开始。"

意境流用1/2/6，种草流用3/4/5。结尾永远是文字压轴，后面不接【图X】。
